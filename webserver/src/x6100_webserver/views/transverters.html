Transverters

Twelve transverters. The dial, the band keys and the log stay on the true RF frequency; the radio is sent the IF (100 kHz to 55 MHz). A low-side LO mixes as RF = LO + IF. A high-side LO mixes as RF = LO − IF and the radio swaps the sideband (LSB with USB, CW with CW-R) while the mode on the screen stays the one you set. Drive 0 leaves the radio's own power; any other value is the most it will send into that transverter, in watts. RX only never transmits. The radio has no band-data or accessory output for switching a transverter: WiFi, the backlight, USB-CAT, the Morse key and the baseband reset are the pins it drives, and the X6200 HOST port is the WR12 receiver.
